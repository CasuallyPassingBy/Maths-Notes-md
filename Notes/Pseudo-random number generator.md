Although we cannot generate true randomness, we can imitate it. Pseudo-random numbers are numbers generated by a deterministic function that appear to be random. These pseudo-random numbers are generated by a single or multiple initial values, called seeds, and applying the function iteratively.

It is easier to generate pseudo-random numbers that true random numbers. If we don't know the seeds we can't distinguish them from true random numbers.

**Def:** Pseudo-random numbers are a deterministic sequence of numbers that behave like a random variable, uniformly distributed on $(0, 1)$. 

There are various methods of generating pseudo-random numbers:

# Linear Congruential Generator

The linear congruential generators are the simplest and most commonly used methods of generating psuedorandom numbers. They are defined recursively: $$X_{n+1} = (a X_n + b) \pmod m,$$where $X$ is the sequence of pseudo-random values, and
- $m$, $0 <m$ is the *modulus*
- $a$, $0 < a <m$ is the *multiplier*
- $b$, $0 \le b < m$ is the *increment*
- $X_0$, $0 \le X_0 < m$ is the *seed* of *starting value* 
are integer constants that specify the generator. If $b = 0$, the generator is often called a *multiplicative congruential generator (MCG)* or *Lehmer RNG*. If $b \neq 0$, the method is called a *mixed congruential generator*. 

We call the period the number of iterations till $X_n = X_0$. The period of a linear congruential generator is called maximum if the period is $m$.

A logical question is how do get a maximum period that still behaves randomly. We can choose them using the *Hull-Dobell Theorem*.

**Hull-Dobell Theorem**: When $b \neq 0$, correctly chosen parameters allow a period equal to $m$, for all seed values. This will occur iff:
- $m$ and $b$ are coprime
- $a-1$ is divisible by all prime factors of $m$
- $a-1$ is divisible by $4$ if $m$ is divisible by $4$

In the special case that $m = 2^n$ for some $n \ge 2$, then by the Hull-Dobell Theorem we can just pick 
- $a-1$ be divisible by $4$
- $b$ odd

```python
def find_period_of_lcg(m:int, a:int, b:int, x_0:int)-> tuple[int, list[int]]:
	x = x_0
	generated_numbers = [x_0]
	for _ in range(m):
		x = (a*x + b) % m
		if x != x_0:
			generated_numbers.append(x)
		else:
			break
	return len(generated_numbers), generated_numbers

modulus = 32
a = 5
b = 3
seed = 1
random_values = find_period_of_lcg(modulus, a, b, seed)
print(random_values)
```

Now to generate numbers in $(0, 1)$ we just divide by $m$. In principle, we could divide by $m-1$, but in the case of $m = 2^n$, for some $n\ge 2$, then it is computationally faster to divide by $m$, since only affects the exponent of the floating point number.

# Fibonacci Generators

Another way to generate pseudo-random numbers by recursively: $$X_n = (X_{n-1} + X_{n-k}) \pmod m,$$where $X$ is the sequence of pseudo-random values, and
- $m$, $0 <m$ is the *modulus*
- $b$, $0 < k$ is the difference
- $X_0$, $0 \le X_j < m$, for $0 \le j < k$ are the *seeds* of *starting values*

We can change operation and get different generators:
- Difference Fibonacci generator $$X_n = (X_{n-1} - X_{n-k}) \pmod m$$
- Multiplicative Fibonacci generator $$X_n = (X_{n-1} + X_{n-k}) \pmod m$$
```python
def fibonacci_generator( base_case:list[int], m:int) -> tuple[int, list[int]]:
	k = len(base_case)
	seen_states = []
	generated_values = base_case.copy()
	while True:
		state = (generated_values[-1], generated_values[-k])
		if state in seen_states:
			break
		seen_states.append(state)
		x = state[0]+ state[1]
		x %= m
		generated_values.append(x)
	
	return len(generated_values) - 1, generated_values[:-1]

print(fibonacci_generator([0, 1], 10))
```

One natural question is how long can the cycles, I decided to try to code a function to compute the maximum cycle

def max_length_fibonacci(m):
	max_length = 0
	for i in range(m):
		for j in range(m):
			length = fibonacci_generator([i, j], m)[0]
			if length > max_length:
				max_length = length
			
	return max_length

print(max_length_fibonacci(10))
