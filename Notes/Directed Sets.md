**Def:** A *directed set* $(A, \le)$ is a nonempty set $A$ with a preorder, with the additonal property that every pair of elements has an upper bound. In other words, for any $a, b\in A$, there exists a $c\in A$ with $a\le c$ and $b\le c$.

There's an equivalent definition. A directed set is a set $A$ with a preorder such that every finite subset $A$ has an upper bound.
