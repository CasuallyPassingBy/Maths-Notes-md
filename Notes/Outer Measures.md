**Def:** A non empty family $\cal E$ of sets is *hereditary* if, whenever $E \in \cal E$ and $F \subseteq E$, then $F \in \cal E$.  ^292706

It is true that the intersection of every collection of hereditary families is again a hereditary family, and that, therefore, corresponding to any family of sets, there is a smallest hereditary family containing it.

We particularly care for hereditary families that are also $\sigma$-rings. If $\cal E$ is a family of sets, we shall denoted the hereditary $\sigma$-ring *generated* by $\cal E$ by $\cal H(E)$. The hereditary $\sigma$-ring generated by $\cal E$ is the family of all sets which can be covered by countably many sets in $\cal E$; if $\cal E$ is a non empty family closed under the formation of countable unions, then $\cal H(E)$ is the family of all sets which are subsets of some set in $\cal E$.

Just as we did to generate the smallest hereditary $\sigma$-ring that contains $\cal E$, we can generate the smallest hereditary ring that contains $\cal E$. It is denoted by Halmos by $\cal J(E)$.

**Def:** An extended real valued set function $\mu^*$ defined on a family $\cal E$ of sets is *subadditive*, if whenever $E, F, E \cup F \in \cal E$, then $$\mu^*(E\cup F) \le \mu^*(E)+ \mu^*(F).$$
Similarly, $\mu^*$ is *finite subadditive* if for every $F \in [\mathcal E]^{<\omega}$ such that $\bigcup F\in \cal E$.  then $$\mu^*\left(\bigcup F\right) = \sum_{E \in F} \mu^*(E).$$
Analogously, $\mu^*$ is *countably additive* if for every if for every $F \in [\mathcal E]^{\omega}$ such that $\bigcup F\in \cal E$.  then $$\mu^*\left(\bigcup F\right) = \sum_{E \in F} \mu^*(E).$$
**Def:** An *outer measure* is an extended real valued, non negative, monotone, and countably subadditive set function $\mu^*$ defined on a hereditary $\sigma$-ring $\cal H$, and such that $\mu^*(\varnothing) = 0$. 

**Th:** If $\mu$ is a measure on a ring $\cal R$ and if, for every $E \in \cal H(R)$, $$\mu^*(E) := \inf\left\{\left.\sum_{n < \omega} \mu(E_n)\;\;\right\rvert\;\; \forall n <\omega(E_n \in \mathcal R), E \subseteq \bigcup_{n <\omega} E_n \right\},$$then $\mu^*$ is an extension of $\mu$ to an outer measure on $\cal H(R)$; if $\mu$ is (totally) $\sigma$-finite, then so is $\mu^*$. The outer measure $\mu^*$ is called the outer measure *induced* by $\mu$. 

**Prop:** If $\mu$ is real valued, finite, non negative, monotone and finitely additive set function defined on a ring $\cal R$ and if $E \in \cal J(R)$, $$\mu^*(E) :=\inf \{ \mu(F) \mid E \subseteq F, F \in \cal R\}, $$then $\mu^*$ is a extended real valued, non negative, monotone and finitely additive set function, with the added property that $\mu^*(E) = \mu(E)$ for all $E\in \cal R$.

**Prop:** If $\lambda^*$ and $\mu^*$ are outer measures on a hereditary $\sigma$-ring $\cal H$, then the set function $\nu^*$, defined on $\nu^*(E) = \max\{\lambda^*(E), \mu^*(E)\}$, is an outer measure on $\cal H$.

**Prop:** If $\{\mu_n^* \mid n < \omega\}$ is a sequence of outer measures on a hereditary $\sigma$-ring $\cal H$ and $\{a_n \mid n < \omega\}$ is a sequence of positive numbers, then the set function $\mu^*$ defined by $$\mu^*(E) = \sum_{n < \omega} a_n\mu_n^*(E)$$is an outer measure on $\cal H$.

# Measurable Sets

**Def:** Let $\mu^*$ be an outer measure on a hereditary $\sigma$-ring $\cal H$. A set $E$ in $\cal H$ is $\mu^*$*-measurable* if for every set $A$ in $\cal H$, $$\mu^*(A) = \mu^*(A \cap E) + \mu^*(A \setminus E).$$
The intuition is that we single out those sets which split every other set additively. 

**Th:** If $\mu^*$ is an outer measure on a hereditary $\sigma$-ring $\cal H$ is the family of all $\mu^*$-measurable sets, then $\overline {\cal S}$ is a ring.

**Obs:** If $\mu^*$ is an outer measure on a hereditary $\sigma$-ring $\cal H$ and if a set $E \in \cal H$ is such that, for every $A \in\cal H$, $$\mu^*(A) \ge \mu^*(A \cap E) + \mu^*(A \setminus E),$$ then $E$ is $\mu^*$-measurable. 

**Prop:** Let $\mu^*$ be an outer measure on a hereditary $\sigma$-ring $\cal H$ and if $E\cap F$ are two sets in $\cal H$ of which one is measurable, then $\mu^*(E) + \ mu^*(F) = \mu^*(E\cup F) + \mu^*(E \cap F)$. 

**Th:** If $\mu^*$ is an outer measure on a hereditary $\sigma$-ring $\cal H$ and if $\overline{\cal S}$ is the family of $\mu^*$-measurable sets, then $\overline{\cal S}$ is a $\sigma$-ring. If $A \in \cal H$ and if $\{E_n \mid n  < \omega\}$ is a disjoint sequence of sets in $\overline{\cal S}$ with $\bigcup_{n  < \omega} E_n = E$, then $$\mu^*(A \cap E) = \sum_{n <\omega} \mu^*(A \cap E_n).$$
This result, where $\overline{\cal S}$ is a $\sigma$-ring, can be proven two ways: one that $\overline{\cal S}$ is a ring and prove it directly, and using partitions just as we did for proving a [[Measures#^29437f|similar result for semirings]]. 

**Def:** If $\mu^*$ is an outer measure on a hereditary $\sigma$-ring $\cal H$, the partition $\{E_n \mid n < \omega\}\subseteq \cal H$ is called a $\mu^*$-*partition* if for every $A\in\cal H$, $$\mu^*(A) = \sum_{n = 0}^\infty \mu^*(A \cap E_n). $$A set $E$ is a $\mu^*$-*set* if the partition $\{E, X\setminus E\}$ is a $\mu^*$-partition. So this brings a little bit more intuition for the definition of $\mu^*$-measurable, since it is equivalent to being a $\mu^*$-set. 

**Prop:**
- The product of two $\mu^*$-partitions is a $\mu^*$-partition.
- If a subpartition of a partition $\{E_n \mid n  <\omega\}$ is a $\mu^*$-partition, then $\{E_n \mid n <\omega\}$ is a $\mu^*$-partition.
- A partition $\{E_n\mid n < \omega\}$ is a $\mu^*$-partition iff each $E_n$ is a $\mu^*$-set.
With this we can conclude that the family of $\mu^*$-sets is a $\sigma$-ring.

**Th:** If $\mu^*$ is an outer measure on a hereditary $\sigma$-ring $\cal H$ and if $\overline{\cal S}$ is the family of all $\mu^*$-measurable sets, then every set of outer measure zero belongs to $\overline{\cal S}$ and the set function $\overline \mu$, defined for $E$ in $\overline{\cal S}$ by $\overline \mu (E) = \mu^*(E)$, is a complete measure on $\overline{\cal S}$. 

The measure $\overline \mu$ is called the measure *induced* by the outer measure $\mu^*$. 

**Prop:** Let $\mu^*$ be real valued, finite, non negative, monotone and finitely additive set function on a hereditary ring $\cal J$. The family of $\mu^*$-measurable sets is a ring, and the set $\mu^*$ is additive on this ring. 

**Prop:** Suppose that $\mu^*$ is an outer measure on a hereditary $\sigma$-ring $\cal H$ and that $\overline{\cal S}$ is the family of $\mu^*$-measurable sets. If $A \in \cal H$ and $\{E_n\mid n <\omega\}$ is an increasing sequence of sets in $\overline{\cal S}$, then $\mu(\lim_{n \to \infty} A \cap E_n ) = \lim_{n \to \infty} \mu(A \cap E_n)$. Similarly, if $\{E_n\mid n <\omega\}$ is a decreasing sequence of sets in $\overline{\cal S}$, and if a set $A\in \cal H$ is such that $\mu^*(A \cap E_m) < \infty$ for at least one value of $m$, then $\mu(\lim_{n \to \infty} A \cap E_n ) = \lim_{n \to \infty} \mu(A \cap E_n)$.
