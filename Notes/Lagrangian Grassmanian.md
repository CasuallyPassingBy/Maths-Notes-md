**Def:** Let $V$ be a real symplectic vector space. The set of all Lagrangian subspaces of $V$ is denoted as $\Lambda(V) \subseteq \text{G}_k(V)$, and is called the *Lagrangian Grassmanian of $V$*. If $V = \Bbb R^{2n}$, then we can write $\Lambda_n$ instead of $\Lambda(\Bbb R^{2n})$.

For the rest of this note $V$ is a real symplectic vector space.

**Prop:** We see that $\text{Sp}(2n,\Bbb R)$ acts transitively over $\Lambda(V)$. 

**Prop:** We see that $\Lambda(V)$ has a unique smooth manifold structure such that the action of $\text{Sp}(2n,\Bbb R)$ is smooth. In addition, we get that the dimension is $\frac12 n(n+1)$, where $2n = \dim V$.
