There is an interesting connection between the tests that use the generalised likelihood ratio and the *Akaike Information Criterion* (AIC) to compare models with different number of parameters. We can derive this in a more general form, with a model with such that its parameter vector belongs to the parameter space $\Theta$, and another model with parameter space $\Theta_0 \subseteq \Theta$, where the difference in dimensions is $r$. Under $H_0$, $$-2 \ln \left(\frac{\max\limits_{\theta\in \Theta_0} L(\theta; \underline x)}{\max\limits_{\theta\in \Theta} L(\theta; \underline x)}\right) = 2\ln \left(\frac{\max\limits_{\theta\in \Theta} L(\theta; \underline x)}{\max\limits_{\theta\in \Theta_0} L(\theta; \underline x)}\right) $$which has an asymptotic distribution of $\chi^2(r)$. We can use this fact to get that the following expected value $$E\left[\ln \left(\max\limits_{\theta\in \Theta} L(\theta; \underline x)\right)- \ln \left(\max\limits_{\theta\in \Theta_0} L(\theta; \underline x)\right)\right] = \frac r2,$$which implies that when $H_0$ is true, the likelihood of the alternative model is on average $r/2$ units greater, where $r$ is the difference in dimension between the parameter space. The idea is to penalise the increment of likelihood that can be gotten when using more parameters. The expression $$2\ln (L(\widehat\theta, \underline x))-2r, $$is known as the Aikake criterion and discriminates in favor of simpler moldes by subtracting $2r$ from the likelihood with more parameters. 

#  $\chi^2$ Goodness-of-Fit Test

In its simples form, we have $k$ cells, where an an experiment must fall into exactly one of the $k$ cells. Let $p_i$, $i \in \{1,\dots, k\}$, the probability of the experiment produces something that falls under the $i$th cell, and let $n_i$ $i \in \{1,\dots, k\}$, the number of results that fell under the $i$th cell, with $n = \sum_{i = 1}^k n_i$ being the number of times the experiment was repeated. In summary we have the following table   

| Cell $i$                                    | 1     | 2     | $\cdots$ | $k$   |
| ------------------------------------------- | ----- | ----- | -------- | ----- |
| Number of observations cell $i$             | $n_1$ | $n_2$ | $\cdots$ | $n_k$ |
| Probability of the result being in cell $i$ | $p_1$ | $p_2$ | $\cdots$ | $p_k$ |
where it is subject to the constraints $$\sum_{i = 1}^k n_i =n, \qquad \text{and} \qquad \sum_{i = 1}^k p_i = 1.$$
If w consider each cell on its own, each time the result falls under each cell we can think of it as success, and after repeating the experiment $n$ times we only care about number of times that was in each cell. With this in mind, we usually associate a binomial distribution to each cell, with $p_i$ the probability of a success in a trial of the experiment, and since there are $n$ experiments, then the expected of the $i$th cell is just the expected value of a binomial, which is $np_i$. In this manner, each of the cells can be see as  

|       | 1      | 2      | $\cdots$ | $k$    |
| ----- | ------ | ------ | -------- | ------ |
| $o_i$ | $n_1$  | $n_2$  | $\cdots$ | $n_k$  |
| $e_i$ | $np_1$ | $np_2$ | $\cdots$ | $np_k$ |

where $o_i$ is the observed quantity and $e_i$ is the expected quantity. We would like to answer the question of, how can we determine if a set of results is considered experimentally is compatible with the expected results given the postulated probabilities in each cell? Formally, we would write it as $$H_0: p_i = \pi_i, i\in \{1,\dots, k\}; $$where $\pi_i$ is the postulated probability of the $i$th cell. Since usually we don't have an alternative hypothesis we use the generalised likelihood ratio.

We see that the likelihood function is $$L(\underline \theta; \underline n) = \prod_{i = 1}^k p_i^{n_i} = \prod_{i = 1}^{k-1} p_i^{n_i} \left(1-\sum_{i = 1}^{k-1} p_i\right)^{n_k}.$$If we examine the log-likelihood we see that $$\ln L(\underline \theta; \underline n) = \sum_{i = 1}^{k-1} n_i\ln p_i + n_k \ln \left(1-\sum_{i = 1}^{k-1} p_i\right).$$When we calculate the gradient and set it equal to $0$, we see that $$\frac{n_i}{p_i} = \frac{n_k}{p_k} \quad \text{or} \quad n_i p_k= n_k p_i $$
We can for all $i$, and get that $$p_k n = n_k, \qquad \text{thus,}\qquad \widehat{p_k} = \frac{n_k}{n}.$$This result can be generalised for the other $p_i$, getting that $$\widehat{p_i} = \frac{n_i}{n}.$$
With this in mind, and under the null hypothesis we get that $$L(\underline \theta ; \underline n) = \prod_{i = 1}^k \pi_i^{n_i},$$ which doesn't have unknown parameters, and the generalised likelihood ratio is $$ \lambda = \frac{\max\limits_{\theta\in \Theta_0}L(\underline \theta; \underline n)}{\max\limits_{\theta\in \Theta}L(\underline \theta; \underline n)} = \prod_{i = 1}^k \left(\frac{n \pi_1}{n_1}\right)^{n_i}.$$
Finding the explicit distribution is going to be complicated, but we can use the asymptotic distribution of $-2\ln \lambda$ as a $\chi^2$ with degrees of freedom equal to the difference in the independent parameters not specified under $\Theta$ and $\Theta_0$, in this case, $k-1$, Then the test consists of considering  $$-2\ln\lambda  =-2 \sum_{i = 1}^k n_i \ln \left(\frac{n \pi_1}{n_1}\right) = -2 \sum_{i = 1}^k n_i \left(\ln \pi_i - \ln \frac{n_i}{n}\right), $$as a random variable distributed as $\chi^2(k-1)$, and the critical region is just $$\mathcal C= \left\{-2 \sum_{i = 1}^k n_i \left(\ln \pi_i - \ln \frac{n_i}{n}\right)\ge c \right\}0,$$where $c$ is such that $$P[-2\ln \lambda \ge c \mid H_0] = \alpha.$$
Karl Pearson proposed the following expression to be the test statistic for the problem of goodness-of-fit:  $$T := \sum_{i = 1}^k \frac{(n_i-e _i)^2}{e _i},$$where $e_i := n \pi_i$ represents the the expected value of cell $i$ under $H_0$. We can use Taylor series see that $$-2\ln \lambda  = \sum_{i = 1}^k \frac{(n_i-n\pi_i)^2}{n_i} + \varepsilon $$where $\varepsilon$ is the error term and $\varepsilon \to 0$ as $n \to \infty$, with probability $1$. This means that we can write as $$-2\ln \lambda  = \sum_{i = 1}^k \frac{(n_i-n\pi_i)^2}{n_i}.$$This expression is similar to Pearson's test statistic, but not quite the same. We use the [[Limit Theorems of Probability#Weak Law of Large Numbers|Weak Law of Large Numbers]] to see that $n_i/n$ converges in probability to $p_i$, meaning that we can substitute $n_i$ with $n\pi$ getting that $$-2\ln \lambda  = \sum_{i = 1}^k \frac{(n_i-n\pi_i)^2}{n\pi_i}=  T,$$which has an asymptotic distribution of $-2\ln \lambda$ of $\chi^2(k-1)$. 

# Independence Test in Contingency Tables

Another use of the generalised likelihood quotient is the following: the problem of proving that two variables are independent. 

A general *two dimensional contigency table*, suppose that the classification has $r$ rows and $c$ columns, and let $P_{ij}$ be the probability of an individual of the population chosen at random falls under the cell corresponding to the $i$th row and $j$th column. Furthermore, let $$ \begin{align*}
P_{i\bullet} &:= \sum_{j = 1}^c P_{ij}, \quad \text{the probability of bieng in the $i$th row, and }\\
P_{\bullet j} &:= \sum_{i = 1}^r P_{ij},\quad \text{the probability of bieng in the $j$th column}.\end{align*}$$
We have the restriction that $$\sum_{i = 1}^r \sum_{j = 1}^c P_{ij} = 1\iff \sum_{i = 1}^r P_{i\bullet} = \sum_{j = 1}^c P_{\bullet j } = 1.$$
![[Pasted image 20251204143947.png]]

Let $n_{ij}$ be the observed frequency of the cell $(i, j)$, then we have that $n$ is the total number of observations, and $$\sum_{i = 1}^r \sum_{j = 1} n_{ij} = n,$$and marginal totals of the rows and columns are $$ n_{\bullet j} := \sum_{i = 1}^r n_{ij}, \qquad n_{i\bullet} := \sum_{j = 1}^c n_{ij}.$$
The problem of proving that two random classified variables are independent can be formulated as $$H_0 : P_{ij} = P_{i\bullet}P_{\bullet j}\quad \text{for  }i \in \{1,\dots, r\} \text{ and } j \in \{1,\dots, c\}.$$
The likelihood function is $$L(\underline \theta; \underline n) = \prod_{i = 1}^r \prod_{j = 1}^c P_{ij}^{n_{ij}}.$$If $H_0$ is true, then $$L(\underline \theta; \underline n) = \prod_{i = 1}^r \prod_{j = 1}^c (P_{i\bullet}P_{\bullet j})^{n_{ij}} = \left(\prod_{i = 1}^r P_{i\bullet}^{n_{i\bullet }}\right)\left(\prod_{j = 1}^c P_{\bullet j}^{n_{\bullet j}}\right).$$Thus, $$\ln L(\underline\theta; \underline n) = \sum_{i = 1}^r n_{i\bullet} \ln P_{i\bullet} + \sum_{j = 1}^c n_{\bullet j} \ln P_{\bullet j}.$$
If we apply the restrictions on the marginal probabilities we see that $$ \begin{align*}&\ln L(\underline \theta; \underline n) = \\&\sum_{i = 1}^{r-1} n_{i\bullet} \ln P_{i\bullet}+ n_{r\bullet }\ln \left(1-\sum_{i = 1}^{r-1}P_{i\bullet}\right) + \sum_{j = 1}^{c-1} n_{\bullet j} \ln P_{\bullet j} + n_{\bullet c}\ln \left(1-\sum_{j = 1}^{c-1}P_{\bullet j}\right).
\end{align*}$$
We see that is very similar to what we did to the $\chi^2$ goodness-of-fit test we get that maximum likelihood estimators are $$ \widehat{P_{i \bullet}} := \frac{n_{i\bullet}}{n}, \quad \widehat{P_{\bullet j}} := \frac{n_{\bullet j}}{n}.$$
In turn, we have maximised the likelihood function in the parametric space defined by $H_0$ which is $$\max_{\theta\in\Theta_0}L(\underline \theta; \underline n) =  \left(\prod_{i = 1}^r \left(\frac{n_{i\bullet}}{n}\right)^{n_{i\bullet }}\right)\left(\prod_{j = 1}^c \left(\frac{n_{\bullet j}}{n}\right)^{n_{\bullet j}}\right).$$
Now we must find the maximum in all the parametric space $$L(\underline \theta; \underline n) = \prod_{i = 1}^r \prod_{j = 1}^c P_{ij}^{n_{ij}},$$and the log-likelihood is $$\ln L(\underline \theta; \underline n) = \sum_{i = 1} ^r \sum_{j = 1}^c n_{ij}\ln P_{ij}.$$Using the restriction of probabilities we get that $$P_{rc} = 1- \sum_{\substack{1 \le i \le r \\ 1 \le j \le c \\ (i, j) \neq (r,c)}} P_{ij}.$$
Then we get that $$ \begin{align*}
\ln L(\underline \theta; \underline n)  &= \sum_{\substack{1 \le i \le r \\ 1 \le j \le c \\ (i, j) \neq (r,c)}}n_{ij}\ln P_{ij} +n_{rc} \ln \left(1-\sum_{\substack{1 \le i \le r \\ 1 \le j \le c \\ (i, j) \neq (r,c)}} P_{ij}\right)
\end{align*}$$
Differentiating $\ln L(\underline \theta; \underline n)$ and setting it equal to $0$ we get that $$\frac{n_{ij}}{P_{ij}} = \frac{n_{rc}}{P_{rc}} \implies n_{ij}P_{rc} = n_{rc}P_{ij}\implies \ \widehat{P_{rc}} = \frac{n_{rc}}{n}.$$We can apply this to all of the probability then $$\widehat{P_{ij}} = \frac{n_{ij}}{n} \quad \text{for $i \in\{1, \dots, r\}$ and $j\in \{1,\dots, c\}$.}$$
Thus, we the maximum likelihood in the total parametric space is  $$\max_{\theta\in \Theta} L(\underline \theta; \underline n) = \prod_{i = 1}^r \prod_{j = 1}^c \left(\frac{n_{ij}}{n}\right)^{n_{ij}}.$$
We know that $$\lambda = \frac{\max\limits_{\theta\in \Theta_0}L(\underline \theta; \underline n)}{\max\limits_{\theta\in \Theta}L(\underline \theta; \underline n)}= \frac{\left(\prod_{i = 1}^r \left(\frac{n_{i\bullet}}{n}\right)^{n_{i\bullet }}\right)\left(\prod_{j = 1}^c \left(\frac{n_{\bullet j}}{n}\right)^{n_{\bullet j}}\right)}{\prod_{i = 1}^r \prod_{j = 1}^c \left(\frac{n_{ij}}{n}\right)^{n_{ij}}}\le   \lambda_0,$$ and that $-2\ln \lambda \sim \chi^2(\nu)$, where $\nu = k -1-s$ and $k$ is the total number of parameters, and $s$ is the number of independent parameters. Since we are restricted by the sums of the probabilities of the rows and columns to be $1$, we get that there are $r+c -2$ independent parameters. Thus, $\nu = rc-1-(r+c-2) = (r-1)(s-1)$. The decision rule is, then we reject $H_0$ with the level of significance $\alpha$ if  $$-2\ln \lambda \ge \omega_{1-\alpha},$$ where $\omega_{1-\alpha}$ is the $1-\alpha$th quantile of the distribution $\chi^2((r-1)(s-1))$.  Using similar arguments to the $\chi^2$ goodness-of-fit test, we get that $$-2\ln \lambda = \sum_{i = 1}^r\sum_{j = j}^c \frac{\left(n_{ij}- \frac{n_{i\bullet}n_{\bullet j}}{n}\right)^2}{\frac{n_{i\bullet}n_{\bullet j}}{n}}+ R_n$$where $R_n \to 0$ where $n \to \infty$ with probability $1$ and we define $$e_{ij} := \frac{n_{i\bullet}n_{\bullet j}}{n}.$$Finally we see that $$T := \sum_{i = 1}^r\sum_{j = j}^c \frac{\left(n_{ij}- e_{ij}\right)^2}{e_{ij}} $$has a distribution which is also $\chi^2(r-1)(c-1)$.
