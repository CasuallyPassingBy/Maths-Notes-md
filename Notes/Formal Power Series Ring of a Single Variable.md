# Construction
Let us consider the abelian group $$R' := \prod_{n \in \Bbb N} R.$$This is the set of functions from $\Bbb N$ to $R$. We would like to give this group a multiplication that is inspired by the multiplication on $R$. To do this, let $(a_n)_{n \in \Bbb N}, (b_n)_{n \in \Bbb N} \in R'$, $$(a_n)_{n \in \Bbb N} * (b_n)_{n \in \Bbb N} := \left(\sum_{k = 0}^n a_k b_{n-k}\right)_{n \in \Bbb N}.$$This operation is the *discrete convolution* of the two sequences. We can check that is associative and distributes over the sum. This means that $R'$ is a ring. Just a couple of things we should keep in mind. If $R$ is commutative, then it is easy to check that so is $R'$. Lastly, if $R$ is unital, then $R'$ is also unital with the multiplicative identity being $$(1, 0, 0 \dots).$$
We usually don't write $R'$. The usual notation is $R[[x]]$, and we write the element $(a_n)_{n \in \Bbb N}\in R'$ as $$\sum_{n = 0}^\infty a_n x^n,$$where $x$ is treated as a formal object. The elements of $R[[x]]$ are called *formal power series*. We call $R[[x]]$ the *ring of formal power series in the variable $x$ with coefficients in $R$*. 

# Properties

**Prop:** The formal power series $\sum_{n = 0}^\infty a_n x^n$ is a unit in $R[[x]]$ iff $a_0$ is unit in $R$. 

if the series $A = \sum_{n = 0}^\infty a_n x^n$ is invertible, then its inverse $B = \sum_{n = 0}^\infty b_n x^n$ where the coefficients are computed via the explicit recursive formula:
$$b_0 = \frac1{a_0}, \qquad b_{n} =-\frac1{a_0} \sum_{k = 1}^{n} a_k b_{n-k}.$$

**Cor:** If $R$ is a field, the formal power series $\sum_{n = 0}^\infty a_n x^n$ is a unit in  iff $a_0\ne 0$. 

**Prop:** If $R$ is an integral domain then $R[[x]]$ is also an integral domain. 

**Prop:** Let $R$ be a commutative unital ring. The principal ideal generated by $x$ in the ring of formal power $R[[x]]$ is a prime ideal iff $R$ is an integral domain. Additionally, $(x)$ is maximal ideal iff $R$ is a field. 

**Prop:** If $F$ is a field, then the field of fractions of $F[[x]]$ is the ring $F((x))$ of formal Laurent series. 

**Prop:** If $F$ is a field, then $F[[x]]$ is a [[Discrete Valuation Rings|discrete valuation ring]]. 

**Cor:** If $F$ is a field, then $F[[x]]$ is an [[Euclidean Domains|Euclidean domain]].
