*Grammars* are restricted class of Post systems that arose in formal language theory. There is a natural hierarchy of grammars, called the *Chomsky hierarchy*, which classifies grammars into four types named $0, 1, 2$, and $3$. The type $2$ and $3$ are just the context-free and right-linear grammars, respectively. A more general class of grammars, called the *type $0$,* or *unrestricted* grammars, are much like context-free grammars, except that productions may be of the more general form $$\alpha →\beta,$$where $\alpha$ and $\beta$ are any strings of terminals and nonterminals whatsoever.

A type $0$ grammar consists of a finite set of such productions. If the left-hand side of a production matches a substring of a sentential form, then the substring can be replaced by the right-hand side of the production. A string $x$ of terminal symbols is *generated* by $G$, that is $x\in L(G)$, if $x$ can be derived from the start symbol $S$ by some finite number of applications in symbols $S \xrightarrow[\, G\, ]{*} x$. 

Type $0$ grammars are a special case of [[Post systems]]: the grammar production $\alpha\to\beta$ corresponds to the Post production$$X\alpha Y \to  X\beta Y.$$
Type $0$ grammars are the most powerful grammars in the Chomsky hierarchy of grammars and generate exactly the Turing-recognisable sets. One can easily build a Turing machine to simulate a given a type $0$ grammar. The machine saves its input $x$ on a track of its tape. It then writes the start symbol $S$ of the grammar on the another track applies productions nondeterminisically, accepting if its input string $x$ is ever generated.

# Classification of Grammars

**Def:** Type $1$ grammars are the *context-sensitive grammars*, $\sf CSG$. A *context-sensitive grammar* contains only productions of the form $\alpha \to \beta$, where $|\alpha| \le |\beta|$, where $|\alpha|$ denotes the length of $\alpha$. Context-sensitive grammars are said to generated context-sensitive languages.

$(*)$**Th:** Context-sensitive grammars are equivalent, except for a trivial glitch involving null string, to nondeterministic linear bounded automata. The bound on the tape in $\sf LBA$s translates to the restriction $|\alpha|\le|\beta|$ for $\sf CSG$s. 

**Def:** A *context-free grammar* contains only productions of the form $\alpha \to \beta$. where $|\alpha| \le |\beta|$ and $\alpha \in V_N$. Context-free grammars generate context-free languages. 

**Def:** A *regular grammar* contains only productions of the form $\alpha \to \beta$, where $|\alpha| \le |\beta|$, $\alpha \in V_N,$ and $\beta$ has the form $aB$ or $a$, where $a\in V_T$ and $B\in V_N$. The languages generated by such grammars are said to be regular.

Let the unrestricted, context-sensitive, context-free, and regular grammars be denoted by the class symbols $T_0$, $T_1$, $T_2$, and $T_3$, respectively. If $L(T_i)$ represents the class of languages that can be generated by the class of $T_i$ grammars, it can be shown that $$L(T_3) \subset L(T_2) \subset L(T_1)\subset L(T_0),$$and therefore the four classes of grammars form a hierarchy.

**Th:** There are context-free languages which are not regular languages.
