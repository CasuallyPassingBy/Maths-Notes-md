**Def:** A topological space $X$ is countably tight, or has countable tightness, if for each $A\subseteq X$ and for each $x\in \overline A$, there is a countable $B\subseteq A$ such that $x\in \overline B$. 

**Def:** Let $X$ be a topological space. We say that $A\subseteq X$ is a countably generated closed set in $X$ if $A\cap C$ is closed in $C$ for any countable $C \subseteq X$. The topological space $X$ is said to be  countably generated, or generated by countable subspaces if $A\subset X$ is a countably generated closed set in $X$ iff $A$ is a closed set.

**Def:** Let $X$ be a topological space. For any set $A\subseteq X$ that satisfies that if $B$ is a countable subset of $A$, then $\overline B\subseteq A$, is called an  $\omega$-closed set. Thus for any cardinal number $\kappa$, the set $A\subseteq X$ is a $\kappa$-closed set if for any $B\subseteq A$ with $|B|\le\kappa$, $\overline B\subseteq A$. 

**Th:** Let $X$ be a topological space. The following statements are equivalent.
- For each $A\subseteq X$, we see that  $$\overline A = \bigcup\overline{[A]^{\le\omega}}.$$
- $X$ is countably generated.
- Every $\omega$-closed set is closed.

**Obs:** We see that every sequential space is countably tight.
