One of the most powerful applications of the theory of flows is to [[partial differential equations]]. 

The number of specialised techniques that have been developed to solve PDEs is staggering (for example [[Fourier Analysis]]). However, it is remarkable fact that real-valued *first odder* PDEs can be reduced to *ordinary differential equations* by means of the theory of flows, and thus can be solved using only ODEs and a little differential-geometric insight but no specialised PDE theory. 

We will only see this technique applied two special cases of first-order equations:
- linear equations;
- quasilinear equations

In coordinates, any first-order PDE for a single unknown function can be written $$F\left(x^1, \dots, x^n, u(x),\frac{\partial u}{\partial x^1}(x),\dots, \frac{\partial u}{\partial x^n}(x)\right)= 0, $$where $u$ is an unknown function of $n$ variables and $F$ is given smooth function of $2n+1$ variables. (Smoothness is not necessary, but it is slightly simpler for purposes of this note). We also need for $F$ and $u$ to be real-valued.

most PDEs have way to many solutions, so in order to get a unique solution one generally stipulates that the solution should satisfy some extra conditions. For first-order equations, the appropuate condition is to specify 'initial values' on a hypersurface: given a smooth hypersurface $S\subseteq \Bbb R^n$ and a smooth function $\varphi: S \to \Bbb R$, we seek a smooth function $u$ that solves the PDE and also satisfies the initial condition$$u|_S = \varphi.$$Finding a solution to the PDE in a neighbourhood of $S$ subject to the initial condition above is called a *Cauchy problem*. Note that not every Cauchy problem has a solution. 

# Linear Equations

The first type of equation we will treat is a first-order *linear PDE*, which is one that depends linearly or affinely on the unkown function and its derivatives. In coordinate form the most general such equation can be written $$a^1(x) \frac{\partial u}{\partial x^1}(x) +\dots+ a^n\frac{\partial u}{\partial x^n}(x)+b(x)u(x) = f(x), $$where $a^1, \dots, a^n, b$ and $f$ are smooth, real-valued functions defined on some open subset $\Omega \subset \Bbb R^n$ and $u$ is the unknown smooth function on $\Omega$.

We can represent the first $n$ terms on the left-hand side represent the action on $u$ of a smooth vector field $A\in {\frak X}(\Omega)$: $$A_x := \left.a^1\frac{\partial}{\partial x^1}\right\rvert_x +\dots + \left.a^n\frac{\partial}{\partial x^n}\right\rvert_x.$$In terms of $A$, we can write the linear PDE in the simple form $Au + bu = f$. In this form, it makes sense on any smooth manifold, and is no more difficult to solve in that generality, so we state our first theorem in that context. The Cauchy problem for $Au + bu =f$ with initial hypersurface $S$ is said to be *noncharacteristic* if $A$ is nowhere tangent to $S$.

**The Linear First-Order Cauchy Problem:** Let $M$ be a smooth manifold. Suppose we are given an embedded hypersurface $S\subseteq M$, a smooth vector field $A\in {\frak X}(M)$ that is nowhere tangent to $S$, and functions $b, f\in {\cal C}^\infty(M)$ and $\varphi \in {\cal C}^\infty (S)$. Then for some neighbourhood $U$ of $S$ in $M$, there exists a unique solution $u\in \mathcal C^\infty(U)$ to the noncharacteristic Cauchy problem $$\begin{align*} Au + bu &= f, \\ u|_S &= \varphi. \end{align*}$$
In this case the proof of the statement is actually the procedure to solving a linear PDE. ^e5452a

The [[Integral Curves, Flows and Flowouts on Smooth Manifolds#Flowout|flowout theorem]] gives us a neighbourhood $\cal O_\delta$ of $\{0\}\times S$ in $\Bbb R\times S$, a neighbourhood $U$ of $S$ in $M$, and a diffeomorphism $\Phi: {\cal O}_\delta \to U$ that satisfies $\Phi(0, p) = p$ for $p\in S$ and $\Phi_*(\partial/\partial t) = A$. Let us write $\hat u = u \circ \Phi$, $\hat f = f \circ \Phi$, and $\hat b = b \circ \Phi$. We see that $\partial \hat u/\partial t = (Au) \circ \Phi$. Thus $u\in \mathcal C^\infty(U)$ satisfies the original Cauchy problem iff $\hat u$ satisfies $$\begin{align*} \frac{\partial \hat u}{\partial t}(t, p) &= \hat f(t, p) - \hat b(t, p)\hat u(t, p), \qquad (t, p) \in \mathcal O_\delta, \\ \hat u(0, p) &= \varphi(p), \qquad p\in S.\end{align*}$$
For each fixed $p\in S$, this is a linear first-order ODE initial value problem for $\hat u$ on the interval $-\delta (p) < t <\delta(p)$. We can solve it using [[Exact Differential Equations and Integrating Factors|integrating factors]], and get that if $$B (\tau, p ) := \int_0^\tau \hat b(\sigma, p)\, d\sigma,$$then $$\hat u(t, p) = e^{-B(t, p)} \left(\varphi(p) + \int_0^t \hat f(\tau,p) e^{B(\tau, p)}\,d\tau\right).$$This is a smooth function of $(t, p)$. Therefore $u = \hat u \circ \Phi^{-1}$ is the unique solution on $U$ to the original Cauchy problem. 

The proof shows how to write down an explicit solution to the Cauchy problem, provided the flow of the vector field $A$ can be found explicitly. The computations are usually easiest if the first choose a parametrization $X: \Omega \to S$, and substitute $X(s)$ for $p$. This amounts to using the canonical coordinates near a regular point to transform the Cauchy problem to an ODE.

**Example:** Let us consider the following Cauchy problem for a smooth function $u(x, y)$ in the plane: $$\begin{align*} x \frac{\partial u}{\partial y}- y \frac{\partial u}{\partial x} &= x, \\ u(x, 0) &= x, \qquad \text{when }x> 0.\end{align*}  $$
The vector field action on $u$ on the left-hand side of the Cauchy problem is really simple get a global flow, $\theta: \Bbb R \times \Bbb R^2 \to \Bbb R^2$, defined as $\theta_t (x, y) = (x \cos t- y \sin t, x\sin t+y \cos t)$. In particular, if we take only the positive $x$-axis, we get that the flow is given by $(x, y) = \Psi(t, s) =\theta_t(X(s))= (s \cos t, s\sin t)$, and $\Psi$ pushed $\partial/\partial t$ forward to the desired vector field. Thus, we transform the original Cauchy problem into $$\begin{align*} \frac{\partial \hat u}{\partial t}(t, s) &= s \cos t \\ \hat u(0, s) &= s.\end{align*}$$We solve this by $\hat u(t,s) = s\sin t+s$, which in terms of the original coordinates of $(x, y)$ is $u(x, y) = y + \sqrt{x^2+y^2}$ the solution to the original problem.

# Quasilinear Equations

A PDE is called *quasilinear* if it can be written as an affine equation in the highest-order derivatives of the unknown function, with coefficients that may depend on the function itself and its derivative of lower order. Thus, in coordinates, a *quasilinear first-order PDE* is a differential equation of the form $$a^1(x, u(x))\frac{\partial u}{\partial x^1}+\dots + a^n(x, u(x)) \frac{\partial u}{\partial x^n} = f(x, u(x)) $$for an unknown real valued function $u(x^1,\dots, x^n)$, where $a^1, \dots, a^n$ and $f$ are smooth real-valued functions defined on some open subset $W\subseteq \Bbb R^{n+1}$. 

We wish to solve a Cauchy problem for this equation with initial condition$$u|_S = \varphi, $$where $S\subseteq \Bbb R^n$ is a smooth, embedded hypersurface, and $\varphi: S \to \Bbb R$ is a smooth function whose graph is contained in $W$. A quasilinear Cauchy problem is said to be *noncharacteristic* if the vector field $A^\varphi$ along $S$ defined by$$A^\varphi|_x = \left.a^1(x, \varphi(x)) \frac{\partial}{\partial x^1} \right\rvert_x+ \dots + \left.a^n(x, \varphi(x)) \frac{\partial}{\partial x^n} \right\rvert_x$$is nowhere tangent to $S$. 

**Quasilinear Cauchy Problem:** If the Cauchy problem $$\begin{align*} a^1(x, u(x))\frac{\partial u}{\partial x^1}+\dots + a^n(x, u(x)) \frac{\partial u}{\partial x^n} &= f(x, u(x)) \\ u|_S &= \varphi.\end{align*} $$is noncharacteristic, then for each $p\in S$ there exists a neighbourhood $U$ of $p$ in $M$ on which there exists a unique solution $u$ to the Cauchy problem. 

The key is to convert the dependent variable $u$ to an additional independent variable. We define the *characteristic vector field* for $$ a^1(x, u(x))\frac{\partial u}{\partial x^1}+\dots + a^n(x, u(x)) \frac{\partial u}{\partial x^n} = f(x, u(x)) $$to be the vector field $\xi$ on $W\subseteq \Bbb R^{n+1}$ given by$$\xi_{(x, z)} := \left.a^1(x,z) \frac{\partial }{\partial x^1} \right\rvert_{(x, z)} + \dots + \left.a^n(x,z) \frac{\partial }{\partial x^n} \right\rvert_{(x, z)} + \left.f(x,z) \frac{\partial }{\partial z} \right\rvert_{(x, z)},$$where we write $(x,z) = (x^1,\dots, x^n, z)$. Suppose $u$ is a smooth function defined on an open subset $V\subseteq \Bbb R^n$ whose graph $\Gamma(u) := \{(x, u(x)) \mid x\in V\}$ is contained in $W$. We see that the equation above holds iff $\xi(z-u(x)) = 0$ for all points of $\Gamma(u)$. Since $z- u(x)$ is a defining function for $\Gamma(u)$, we see that $u$ solves the desired equation iff $\xi$ is tangent to $\Gamma(u)$. The idea is to construct the graph of $u$ as a flowout by $\xi$ from a suitable initial manifold. 

Surprisingly, we in order to get a solution we need to use the [[Transversailty Theorems for Smooth Manifolds#^dadb54|Local Characterisation of Graphs]]. 

To find an explicit solution to a quasilinear Cauchy problem, we begin by choosing a smooth local parametrization of $S$, written as $s \mapsto X(s)$ for $s = (s^2,\dots,s^n)\in \Omega \subseteq\Bbb R^{n-1}$. Then the map $\widetilde X: \Omega \to \Bbb R^{n+1}$ given by $\widetilde X (s) := (X(s), \varphi(X(s)))$ is a local parametrization of $\Gamma(\varphi)$, and a local parametrisation of $\cal S$ (the flowout of $\Gamma(\varphi)$) is given by$$\Psi(t, s) = \theta_t(\widetilde X(s)), $$where $\theta$ is the flow of $\xi$. To rewrite $\cal S$ as a graph, we invert the map $\pi \circ \Psi: \Omega\to \Bbb R^n$ locally by solving for $(x^1,\dots, x^n)$ in terms of $(t, s^1,\dots, s^n)$: then the $z$-component of $\Psi$, written as a function of $(x^1,\dots, x^n)$, is the solution to the Cauchy problem.

**Example:** Suppose we wish to solve the following quasilinear Cauchy problem in the plane: $$\begin{align*} (u+1) \frac{\partial u}{\partial x}+ \frac{\partial u}{\partial y} &= 0, \\ u(x, 0) = 0.\end{align*} $$The initial hypersurface $S$ is the $x$-axis, and the initial value is $\varphi(x, 0) = x$. The vector field $A^\varphi = (x+1) \partial_x + \partial_y$, which is nowhere tangent to the $x$-axis, so the problem is noncharacteristic.

The characteristic vector field is the following vector field on $\Bbb R^3$: $$\xi := (z+1) \frac{\partial}{\partial x}+ \frac{\partial}{\partial y}. $$We wish to find the flowout of $\xi$ from $\Gamma(\varphi)$. We can parametrise $S$ by $X(s) := (s,  0)$ for $s\in \Bbb R$, and then $\Gamma(\varphi)$ is parametrised by $\widetilde X(s) := (s, 0, s)$. We get the following system of ODEs associated to $\xi$, $$\begin{align*} \dot x &= z+1 \\ \dot y &= 1 \\ \dot z &= 0\end{align*}$$with initial conditions $(x, y, z) = (s, 0, s)$. The solution is $z = s$, and $y = t$, thus $\dot x = s+1$, and $x = (s+1)t +s$. We get that the flowout of $\xi$ starting from $\widetilde X(s)$ is parametrised by $$\Psi(t, s) = (s+t+st, t, s). $$The image of this map is the graph of our solution. To reparametrize the graph in terms of $x$ and $y$, we invert the map $\pi \circ \Psi$; that is we solve $(x, y) = (s+t+st, t)$ (locally) for $t$ and $s$, yielding $$(t, s) = \left(y, \frac{x-y}{y+1}\right), $$and therefore on the flowout manifold we have $z = s = (x-y)/(y+1)$. The solution for our Cauchy problem is $u(x, y) = (x-y)/(1+y)$. This solution is only defined in a neighbourhood of $S$, the set where $y > -1$, not the while plane. 

The integral curves of $\xi$ in $\Bbb R^{n+1}$ are called the *characteristic curves*, or *characteristics* of the PDE. This solution technique, which boils down to constructing the graph of $u$ as a union of the characteristic curves, is called the *method of characteristics*. 

We see that both of our theorems only assert existence and uniqueness of a solution in a neighbourhood of the initial manifold. Cauchy problems do not always admit global solutions, and when global solutions do exist, they might not be unique. The basic problem is that the characteristic curves passing through the initial hypersurface might not reach all points of the manifold. Quasilinear problems have the added complication that characteristic curves in $\Bbb R^{n+1}$ might cease to be transverse to the fibres of the projection $\Bbb R^{n+1}\to \Bbb R^n$, or even if they are transverse, their projection into $\Bbb R^n$ starting at different points of $\Gamma(\varphi)$ might cross each other, and even though the characteristics curves themselves do not. 

## Euler Vector field an Homogeneous functions

**Def:** We define the *Euler vector field on $\Bbb R^n$* whose values at $x\in \Bbb R^n$ to be $$V_x := \left. x^i \frac{\partial}{\partial x^i}\right\rvert_x $$is smooth because its coordinate functions are linear. 

**Def:** Let $c> 0$ be a positive real number, and let $f:\Bbb R^n \setminus \{0\}\to \Bbb R$ be a smooth function that is *positively homogeneous of degree $c$*, meaning that $f(\lambda x) = \lambda^c f(x)$ for all $\lambda > 0$ and $x\in \Bbb R^n \setminus\{0\}$. 

**Euler's Homogeneous Function Theorem:** We see if $f$ is positively homogeneous of degree $c$, then $Vf = cf$, where $V$ is the Euler vector field. 

**Th:** If $f\in \mathcal C^\infty(\Bbb R^n \setminus\{0\})$ satisfies $Vf = cf$, where $V$ is the Euler vector field and $c\in\Bbb R$, then $f$ is positively homogeneous of degree $c$.

We can solve this as the solution to a linear partial differential equation. This solution actually tells us that the if we have a smooth function $g: \Bbb S^{n-1}\to \Bbb R$, then we can extend this function uniquely to $\Bbb R^n\setminus \{0\}$ by multiplying a factor $\|x\|^c$, this extended function is positively homogeneous of degree $c$.
