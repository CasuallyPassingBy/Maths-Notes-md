**Def:** If $M$ is a smooth manifold, a *smooth $p$-simplex in $M$* is a map $\sigma:\Delta_p\to M$ that is smooth in the sense that it has a smooth extension to a neighbourhood of each point. The subgroup of $C_p(M)$ generated by sooth simplices is denoted by $C_p^\infty(M)$ and called the *smooth chain group in degree $p$*. Elements of this group, which are finite formal linear combinations of smooth simplices are called *smooth chains*. Because the boundary of a smooth simplex is a smooth chain, we define the *$p$th smooth singular homology group of $M$* to be the quotient group: $$H^\infty_p(M) := \frac{\ker(\partial: C^\infty_p(M) \to C^\infty_{p-1}(M))}{\text{Im}(\partial : C^\infty_{p+1}(M) \to C^\infty_p(M))}.$$
**Obs:** Note that the inclusion map $\iota: C^\infty_p(M) \hookrightarrow C_p(M)$ commutes with the boundary operator and so induces a map on homology $\iota_*: H^\infty_p(M) \to H_p(M)$, by $\iota_*[c] = [\iota(c)]$. 

**Lemma:** Let $M$ be smooth manifold, and let $\Delta$ be a geometric $p$-simplex in $\Bbb R^n$, and let $f: \partial \Delta\to M$ be a continuous map whose restriction to each individual boundary face $\Delta$ is smooth, Then $f$ is smooth when considered as a map from the entire boundary $\partial \Delta$ to $M$.

**Lemma:** Let $M$ be a smooth manifold. For each integer $p\ge 0$ and each singular $p$-simplex $\sigma: \Delta_p \to M$, there exists a continuous map $H_\sigma: \Delta_p \times I\to M$ such that the following hold.
- $H_\sigma$ is a homotopy from $\sigma(x) = H_\sigma(x, 0)$ to a smooth $p$-simplex $\widetilde\sigma(x) = H_\sigma(x, 1)$,
- For each face map $F_{i, p}:\Delta_{p-1}\to \Delta_p$, $$H_{\sigma\circ F_{i, p}} = H_\sigma \circ (F_{i, p}\times \text{Id}_I), $$or more explicitly, $$ H_{\sigma\circ F_{i, p}}(x, t)= H_\sigma( F_{i,p}(x), t),  \qquad (x, t)\in \Delta_{p-1}\times I.  $$
- If $\sigma$ is a smooth $p$-simplex, the $H_\sigma$ is the constant homotopy $H_\sigma(x, t) = \sigma(x)$.

**Smooth Singular vs Singular Homology:** For any smooth manifold $M$, the map $\iota_*: H^\infty_p(M) \to H_p(M)$ induced by inclusion is an isomorphism.
