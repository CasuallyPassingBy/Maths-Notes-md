**Def:** Let $X$ be a locally compact Hausdorff space and let ${\scr I}_+(X)$ be the set of all $[0,\infty]$-valued lower semicontinuous functions on $X$. Suppose that $I$ is a positive linear functional on $\mathcal C_c(X)$, in Bourbaki's terminology, $I$ is a *positive Radon measure on $X$*. Bourbaki defines a function $I^*: {\scr I}_+(X) \to [0, \infty]$ by $$I^*(f) := \sup\{I(g) \mid \mathcal C_c(X) \land 0\le g\le f\} $$and then uses the formula  $$I^*(f) = \inf\{I^*(h) \mid h\in{\scr I}_+(X) \land f\le h\}$$to extend $I^*$ to the set of all $[0, \infty]$-valued functions on $X$. He checks that that $I^*$ satisfies $$I^*(f+g) \le I^*(f) + I^*(g) \quad \text{and}\quad I^*(af) = aI^*(f)$$for all $f, g: X \to [0,\infty]$ and all $0< a<\infty$. Note that $I^*(0) = 0$. 

Let define the set ${\scr F}^1$ of function $f: X\to \Bbb R$ for which $I^*(|f|) <\infty$. It is clear that ${\scr F}^1$ is a $\Bbb R$-vector space and the function $N_1: {\scr F}^1 \to \Bbb R$ defined by $N_1(f) := I^*(|f|)$ is a seminorm on ${\scr F}^1$. Let us note that $\mathcal C_c(X) \subseteq\mathcal F^1$. Bourbaki then defines ${\scr L}^1(X, I)$ to be the closure of $\mathcal C_c(X)$ in $\mathscr F^1$, with the topology determined by $N_1$, and extends $I$ from $\mathcal C_c(X)$ to $\mathscr L^1(X, I)$ by letting $$I(f) := \lim_{n \to \infty} I(f_n) $$hold whenever $(f_n)_{n<\omega}$ is a sequence of functions in $\mathcal C_c(X)$ for which $\lim\limits_{n\to \infty}N_1(f_n-f) =0$. He calls the function that belong to $\mathscr L^1(X, I)$ *$I$-integrable*, and he calls the extension of $I$ to $\mathscr L^1(X, I)$ the *integral*; he often writes $$\int f\,d I $$in place of $I(f)$. He calls a function $f: X\to\Bbb R$ $I$-measurable if for each compact subset $K$ of $X$ and each $\varepsilon>0$ there is a compact subset $L$ of $K$ that satisfies $I^*(\chi_{K\setminus L}) <\varepsilon$ and is such that the restriction of $f$ to $L$ is continuous. Furthermore, he calls a subset $A$ of $X$ $I$-*integrable* if $\chi_A$ is $I$-integrable and $I$-*measurable* if $\chi_A$ is $I$-measurable. 

Let $X$ be a locally compact Hausdorff space, $I$ be a positive linear functional on $\mathcal C_c(X)$. We defined an outer measure $\mu^*$ by $$\mu^*(U) := \sup\{I(f) \mid f\in \mathcal C_c(X) \land f \prec U\}, $$whenever $U$ is an open subset of $X$ and if $A\subseteq X$ $$\mu^*(A) := \inf\{\mu^*(U) \mid U\in \tau \land A\subseteq U\}.$$Let ${\scr M}_{\mu^*}$ be the $\sigma$-algebra of $\mu^*$-measurable sets. We know that $\mathcal B(X) \subseteq {\scr M}_{\mu^*}$, and that the restrictions $\mu$ and $\mu_1$ of $\mu^*$ to $\mathcal B(X)$ and to ${\scr M}_{\mu^*}$ are regular measures. For more details check [[Space of Continuous Compactly Supported Functions#Riesz Representation Theorem|this]]. 

**Th:** Let $X$ be a locally compact Hausdorff space, let $I$ be a linear functional on $\mathcal C_c(X)$, let $\mathscr L^1(X, I)$ be defined as above, and let $\mu^*$, $\mathscr M_{\mu^*}$, and $\mu_1$ be as defined above. Then
- $\mathscr L^1 (X, I) = \mathscr L^1(X, \mathscr M_{\mu^*}, \mu_1, \Bbb R)$ 
- $\int f\, dI = \int f\,d\mu_1$ holds for each $f\in \mathscr L^1(X, I)$,
- a subset $A$ of $X$ is $I$-measurable iff it belongs to $\mathscr M_{\mu^*}$, and
- a function $f: X\to\Bbb R$ is $I$-measurable iff it is $\mathscr M_{\mu^*}$-measurable.

Note that if $I$ is a positive linear function on $\mathcal C_c(X)$, then for each compact subset $K$ of $X$ there is a number $c_K$ such that $|I(f) |\le c_K \|f\|_\infty$ holds whenever $f\in \mathcal C_c(X)$ and satisfies $\text{supp}(f) \subseteq K$. 

Bourbaki calls a linear functional $I$ on $\mathcal C_c(X)$ a *Radon measure* on $X$ if it satisfies that for each compact subset $K$ of $X$ there is a number $c_K$ such that $|I(f) |\le c_K \|f\|_\infty$ holds whenever $f\in \mathcal C_c(X)$ and satisfies $\text{supp}(f) \subseteq K$.  Since each difference of positive linear functionals on $\mathcal C_c(X)$.

We see that every Bourbaki Radon measure on $X$ is the difference of Bourbaki positive Radon measures on $X$. Thus the set of Bourbaki Radon measure on $X$ is the vector space generated by the set of positive linear functionals on $\mathcal C_c(X)$. 

**Prop:** If $I$ is a Bourbaki Radon measure on the locally compact Hausdorff space $X$, then there are regular Borel measure $\mu_1$ and $\mu_2$ on $X$ such that $I(f) = \int f\,d\mu_1 - \int f\, d\mu_2$ hold for each $f\in \mathcal C_c(X)$.
