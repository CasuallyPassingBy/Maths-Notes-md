**Real Induction:** Let $a, b\in \Bbb R$ with $a < b$, and $S\subseteq [a, b]$. If $S$ satisfies the following conditions
- $a\in S$
- If $[a, x]\subseteq S$, then there's a $\delta> 0$ such that $[x, x+\delta]\subseteq S$.
- If $[a, x) \subseteq S$, then $x\in S$
Then $S = [a,b]$.

Real induction can be used to prove important theorems like [[Continuity on R#Extreme Value Theorem|Extreme Value Theorem]] and the [[Intermediate Value Theorem in R]].
