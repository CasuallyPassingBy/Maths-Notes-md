**Def:** Let $D$ be the degree matrix of a graph and $A$ be the adjacency matrix. Then $D+A$ is called the signless Laplacian. Similarly, we call $I + D^{-1/2}AD^{-1/2}$ the normalised signless Laplacian. 

# The Continuous Analogue of the signless Laplacian ($D+A$)

**Author:** Mei  
**Subject Classification:** Geometric Deep Learning, Manifold Learning, Spectral Geometry  
**Key Operators:** Laplace-Beltrami Operator ($\Delta_M$), Normalized Anti-Laplacian ($\mathbb{L}$).
*Inspired by the asymptotic analysis frameworks of [Belkin & Niyogi](file:///home/passingmei/Downloads/TT_JCSS_08.pdf) (2005/2006) and [Coifman & Lafon (2006)](file:////home/passingmei/Downloads/Diffusion_maps.pdf).*

Let $M$ be a compact manifold. 

Given a sample of $n$ points $x_1, \dots, x_n$ from $M$ we construct the completed weighted graph associated to that point cloud by taking $x_1,\dots, x_n$ as vertices of the graph and taing the edge weights to be $w_{ij}^t := K_M^t(x_i, x_j)$, where $K_M^t$ is the heat hernel of $M$. The corresponding graph signless Laplacian $Q_n^t$ is given by  $$Q_n^t = \begin{dcases}w_{ij}^t & \text{ if }i \neq j, \\ \sum_{k = 1}^n w_{ik}^t & \text{ if }i = j. \end{dcases} $$
We think $Q_n^t$ as on operator on functions defined on the data points $$Q_n^t f(x_i) = f(x_i) \sum_{j = 1}^n K_M^t(x_i, x_j) + \sum_{j = 1}^n f(x_j) K_M^t (x_i, x_j). $$
**Point cloude Signless Laplacian Operator:** We immediately see that this formulation to any function on the ambient space and will denote the corresponding operator by $\mathbf Q_n^t$:  $$\mathbf Q_n^t f(x) := f(x) \frac1n\sum_{j = 1}^n K_M^t(x, x_j) + \frac1n \sum_{j = 1}^n f(x_j) K_M^t(x, x_j). $$We see that $\mathbf Q_n^t f(x_i) =\frac1n Q_n^t f(x_i)$. We call the operator $\mathbf Q_n^t$ the *signless Laplacian associated to the point cloud $x_1, \dots, x_n$.* 

Given a measure $\nu$ on $M$ we construct the corresponding operator  $$\mathbf Q^t f(x) : = f(x) \int_M K_M^t(x, y)\, d\nu(y) + \int_M K_M^t(x, y) f(y)\, d\nu(y). $$
We see that $\mathbf Q_n^t$ is simply a special case of $\mathbf Q^t$ corresponding average measure of the Dirac measures of $x_1,\dots, x_n$. 

Let us suppose that $M$ is isometrically embedded into $\Bbb R^N$. We will first assume that the data is sampled from the uniform probability measure given by the induced metric on $M$, i.e., the induced metric scaled by a factor of $(\text{vol}(M))^{-1}$, let us denote the corresponding probability measure $\mu$. 

Given the data $S_n := \{x_1,\dots, x_n\}\subseteq \Bbb R^N$ sampled i.i.d. from this probability distribution we construct the associated signless Laplacian operator $\mathbf Q_n^t$. 

The Laplace-Beltrami operator $\Delta_M$ is a second-order differential operator. The family of diffusion operators $H_M^t: C^\infty(M) \to C^\infty(M)$ is generated by the heat kernel $K_M^t(x,y)$ via the integral representation:
$$H_M^t(f)(x) = \int_M K_M^t(x, y) f(y)\, d\mu(y)$$
This family of operators satisfies the heat equation:
$$\frac{\partial}{\partial t} H_M^t(f) + \Delta_M  H_M^t (f) = 0 \quad \text{and}\quad  \lim_{t \to 0} H^t_M (f) = f$$
for any continuous function $f: M \to \Bbb R$.

Since the data points $x_1, \dots, x_n$ are sampled i.i.d. from the uniform probability measure $\mu$, for any fixed $x\in M$ and any continuous function $f$, the terms $K_M(x, x_j)$ and $f(x_j)K_M^t(x, x_j)$ are independent random variables. By the Weak Law of Large Numbers we get that  $$\begin{align*}\frac1n \sum_{j = 1}^n K_M^t(x, x_j) &\stackrel{\Bbb P}{\longrightarrow} \int_M K_M^t(x, y)\, d\mu(y), \\
\frac1n \sum_{j = 1}^n f(x_j) K_M^t(x, x_j) &\stackrel{\Bbb P}{\longrightarrow} \int_M K_M^t(x, y) f(y)\, d\mu(y).
\end{align*} $$Therefore, pointwise for any $x\in M$, we have:  $$\lim_{n\to \infty} \mathbf Q_n^tf(x) = \mathbf Q^tf(x) $$in probability.

We are going to define an auxiliary function. Let $$d_M^t(x) := \int_M K_M^t(x, y)\, d\mu(y).$$We see that $d_M^t$ is a continuous analogue of degree. We would like to see how it behaves. For us to be able to simplify the preceding integrals, we need a particular expression of the heat kernel:  $$ K_M^t (x, y) = \sum_{n = 0}^\infty e^{-t\lambda_n} \phi_n(x) \phi_n(y),$$where $\phi_n$ is an eigenfucntion of $\Delta_M$ with eigenvalue $\lambda_n$. We note that this decomposition is possible because $M$ is compact. Additionally, we know that the set $\{\phi_n\}_{n = 0}^\infty$ forms an orthonormal basis for $L^2(M, \mu)$. With this in mind, we only need to calculate $H_M^t(\phi_n)$. 

Let $n \in \Bbb N$. Then $$\begin{align*}
H_M^t(\phi_n) &= \int_M K_M^t(x, y) \phi_n(y)\, d\mu(y) = \int_M \sum_{m = 0}^\infty e^{-t\lambda_m} \phi_m(x) \phi_m(y) \phi_n(y)\, d\mu(y)\\
&= \sum_{m = 0}^\infty e^{-\lambda_m t} \phi_m(x) \int_M \phi_m(y)\phi_n(y)\, d\mu (y)\\ &=  \sum_{m = 0}^\infty e^{-\lambda_m t}\phi_(x) \delta_{m ,n} = e^{-\lambda_n t} \phi_n(x).
\end{align*}
$$This means that if $f\in L^2(M, \nu)$, then we can write it as $f = \sum_{n = 0}^\infty c_n \phi_n$, then when we apply $H_M^t$ to $f$ we get that $$H_M^t (f) = \sum_{n = 0}^\infty c_ne^{-t\lambda_n } \phi_n = \sum_{n = 0}^\infty c_ne^{-t\Delta_M } \phi_n = e^{-t\Delta_M} \sum_{n = 0}^\infty c_n \phi_n = e^{-t\Delta_M} f.$$
This lets us rewrite our $\mathbf Q^t$ operator as $$\mathbf Q^t = d_M^t I + e^{-t\Delta_M}.$$
Let us note that $d_M^t$ is just $H_M^t$ applied to the constant function $1$. We get that $$d_M^t(x) = e^{-t\Delta_M} \mathbf 1 = e^{-t\cdot 0} \cdot  \mathbf 1 = \mathbf 1.$$Lastly we get that $$\mathbf Q^t  = I+ e^{-t\Delta_M},$$when $M$ is a compact manifold. 

We see that if were to apply this this technique to the Laplacian $L := D- A$, we would get that the continuous analogue is actually represented as $$\mathbf L^t  = I -e^{-t\Delta_M},$$which satisfies $\mathbf L^t \to 0$ as $t\to  0$. Lastly, by calculating the following limit we see $$\lim_{t\to 0} \frac{\mathbf L^t}{t}  = \Delta_M,$$just as it was proven by Bilken and Niyogi.

The reason we don't consider something similar for $\mathbf Q^t$ is because it has the same behaviour as its discrete analogue: adding the value of the function to the weighted average of neighbours. 

In realistic data, points are sampled according to a non-uniform probability density function $p(x) > 0$ on $M$, altering the sampling measure to $d\nu(y) = p(y)\, d\mu(y)$ Without correction, the unnormalized continuous degree function absorbs the local data density $$d_M^t (x) = \int_M K_M^t(x, y)\, d\nu(y)= \int_M K_M^t(x, y) p(y)\, d\mu(y) = (e^{-t\Delta_M} p)(x).$$
Now, we consider a new kernel $$K^{t, \alpha}_M (x, y) := \frac{K_M^t(x,t)}{(d^t_M(x))^\alpha (d_M^t(y))^\alpha},$$where $\alpha \in [0,  1]$. 

We note that if we have a point cloud $\mathcal S:= \{x_1, \dots, x_n\}$ on $M$ sampled i.i.d. from the new probability $\nu$, we can define an $\alpha$-normalised signless Laplacian, $\mathbf Q^{t, \alpha}_n$, as $$\mathbf Q_n^{t, \alpha} f(x) := f(x) \frac1n\sum_{j = 1}^n K_M^{t, \alpha}(x, x_j) + \frac1n \sum_{j = 1}^n f(x_j) K_M^{t, \alpha}(x, x_j). $$By the same argument, we see that $$\begin{align*}\frac1n \sum_{j = 1}^n K_M^{t, \alpha}(x, x_j) &\stackrel{\Bbb P}{\longrightarrow} \int_M K_M^{t, \alpha}(x, y)\, d\nu(y), \\
\frac1n \sum_{j = 1}^n f(x_j) K_M^{t, \alpha}(x, x_j) &\stackrel{\Bbb P}{\longrightarrow} \int_M K_M^{t, \alpha}(x, y) f(y)\, d\nu(y).
\end{align*} $$
This, in turn, let's us consider generalisations of already known functions:$$d^{t, \alpha}_M(x) := \int_M K_M^{t, \alpha}(x,y)\, d\nu(y) = \int_M K_M^{t, \alpha}(x, y)p(y)\, d\mu(y) $$and  $$H_M^{t, \alpha}f := \int_M K^{t, \alpha}_M (x, y) f(y)\, d\nu(y) = \int_M K^{t, \alpha}_M(x, y) f(y)p(y)\, d\mu(y), $$where $d^{t, \alpha}_M$ is the continuous degree function to the $\alpha$-normalization.

Let $f:M \to \Bbb R$ be a continuous function. Then we see that $$
\begin{align*}
H_M^{t, \alpha} f(x) &= \int_M K_M^{t, \alpha}(x, y)f(y)p(y)\, d\mu(y)  = \int_M \frac{K_M^{t}(x, y)}{d^t_M(x)^\alpha d^t_M(y)^\alpha}f(y)p(y)\, d\mu(y) \\
&=\frac1{d^t_M(x)^\alpha}\int_M K_M^t(x, y)\frac{f(y)p(y)}{d^t_M(y)^\alpha}\, d\mu(y) 
\\ &= \frac1{d^t_M(x)^\alpha} H_M^t\left(\frac{fp}{(d^t_M)^\alpha} \right)(x) = \frac1{d^t_M(x)^\alpha}e^{-t\Delta_M}\left(\frac{fp}{(d^t_M)^\alpha} \right)(x).
\end{align*}
$$
The continuous $\alpha$-normalized signless Laplacian operator $\mathbf Q^{t, \alpha}$ is defined as $$\mathbf Q^{t, \alpha} f(x) := d^{t, \alpha}_M (x) f(x) + H^{t, \alpha}_Mf(x).$$By the above convergence argument we see that $$
\lim_{n\to \infty} \mathbf Q^{t, \alpha}_n = \mathbf Q^{t, \alpha}.
$$

## 2. Robustness to Non-Uniform Sampling ($\alpha$-Normalization)

In realistic data regimes, points are sampled according to a non-uniform probability density function $p(x) > 0$ on $M$, altering the sampling measure to $d\nu(y) = p(y)dV(y)$, where $dV$ is the natural volume element. Without correction, the unnormalized continuous degree function absorbs the local data density:
$$d_M^t(x) = \int_M K_M^t(x, y) p(y) \, dV(y) = e^{-t\Delta_M}p(x) \approx p(x) - t\Delta_M p(x) + O(t^2)$$

This introduces a density bias, mixing the underlying geometric curvature with the clumping of data points. To recover pure geometry, we implement the continuous analogue of the Coifman-Laffon $\alpha$-normalization. We construct an empirical density proxy from the unnormalized degree and modify the kernel: $$\tilde{K}_M^t(x, y) = \frac{K_M^t(x, y)}{d_M^t(x)^\alpha d_M^t(y)^\alpha}$$
By setting **$\alpha = 1$**, the normalization scales the kernel by the inverse of the densities. Let $\tilde{d}_M^t(x) = \int_M \tilde{K}_M^t(x, y) p(y) dV(y)$ be the renormalized degree. As $t \to 0$:
$$\tilde{K}_M^t(x, y) \approx \frac{K_M^t(x, y)}{p(x)p(y)}$$
Substituting this into the density-weighted integral cancels out $p(y)$ inside the operator:
$$\mathbf{Q}^t_{norm} f(x) = f(x)\tilde{d}_M^t(x) + \int_M \tilde{K}_M^t(x, y) f(y) p(y) \, dV(y) \longrightarrow I + e^{-t\Delta_M}$$

This proves that the low-pass, non-contractive spectral properties of the continuous operator are mathematically invariant to non-uniform data density when properly normalized.

## 3. Spectral Mapping & Continuous Taxonomy

By the Spectral Mapping Theorem, since $\mathbf{Q}^t$ is a smooth function of the Laplace-Beltrami operator, it shares the exact same eigenfunctions $\phi_n$ as $\Delta_M$. If $\lambda_n$ is an eigenvalue of $\Delta_M$, the corresponding continuous eigenvalue $\gamma(\lambda_n)$ of $\mathbf{Q}^t$ is:
$$\gamma(\lambda_n) = 1 + e^{-t\lambda_n}$$

We map this continuous spectrum directly to the graph filter taxonomy established by Aguas Fonseca (2026):
1. **Strict Low-Pass Filtering:** The frequency response function $\gamma(\lambda) = 1 + e^{-t\lambda}$ is strictly decreasing as the manifold frequency $\lambda \to \infty$. This mathematically guarantees that high-frequency noise is dampened across the continuous domain.
2. **Neither Contractive nor Expansive:** At the lowest manifold frequency ($\lambda_0 = 0$), the maximum response is $\gamma(0) = 1 + e^0 = 2$. Because $\max |\gamma(\lambda)| > 1$, the operator is **not contractive**, successfully evading the information collapse typical of over-smoothing.
   * As $\lambda \to \infty$, $\gamma(\lambda) \to 1$. Because the filter does not grow without bound at high frequencies, the continuous operator is strictly **not expansive** across the non-zero spectrum.

## 4. The Local Differential Bridge (Small-$t$ Approximation)

To link this continuous operator back to computationally efficient, local message passing in Graph Neural Networks, we analyze the functional behavior for small values of $t$. Taking the Taylor series expansion of the exponential diffusion operator gives:
$$e^{-t\Delta_M} = I - t\Delta_M + \frac{t^2}{2}\Delta_M^2 - \dots$$

Substituting this expansion back into our continuous operator yields:
$$\mathbf{Q}^t = I + \left( I - t\Delta_M + \frac{t^2}{2}\Delta_M^2 - O(t^3) \right) = 2I - t\Delta_M + O(t^2)$$

### Practical Real-World Realization
In discrete data applications, the true intrinsic manifold heat kernel $K_M^t(x, y)$ is unobservable. Following Varadhan's Asymptotic Lemma, the ambient Euclidean distance $\|x-y\|^2$ acts as a local proxy for the true squared geodesic distance $d_M(x, y)^2$ as $t \to 0$:
$$K_M^t(x, y) = (4\pi t)^{-d/2} e^{-\frac{\|x-y\|^2}{4t}} \left( 1 + O(t) \right)$$

### Implications for Graph Convolutions
Computing dense non-local integral operators or long-range diffusion matrices is computationally prohibitive in deep networks. The small-$t$ evaluation $2I - t\Delta_M$ provides a powerful theoretical justification for architectures like SumGCN. It demonstrates that a highly localized, sparse graph convolution layer—which only aggregates messages from immediate $1$-hop neighbors—acts as a mathematically rigorous, first-order approximation of a global, non-contractive continuous manifold filter.

## 5. Numerical Verification & Proof of Concept

To validate the discrete-to-continuous spectral convergence of the Normalized Anti-Laplacian operator and evaluate the empirical efficacy of the continuous $\alpha$-normalization framework, we outline a series of synthetic manifold simulations. This numerical verification bridges the theoretical continuum limits derived in Section 3 with discrete, finite point clouds.

### 5.1 Synthetic Manifold Configurations
The simulations utilize two distinct geometric embeddings in ambient Euclidean space $\mathbb{R}^3$:

1. **The 2D Unit Sphere ($\mathbb{S}^2$):** A compact manifold with constant positive curvature. The analytical eigenvalues of its Laplace-Beltrami operator are explicitly known and given by $\lambda_k = k(k+1)$ with multiplicity $2k+1$ for $k \in \mathbb{N}_0$.
2. **The Swiss Roll:** A non-linear, rolled 2D grid embedded in $\mathbb{R}^3$, widely used in manifold learning to test whether an operator can recover intrinsic geodesic structures despite severe ambient coordinate distortion.

### 5.2 Point Cloud Generation and Sampling Regimes
For each manifold, a finite point cloud of size $n = 2000$ is sampled under two distinct probabilistic regimes:
* **Uniform Sampling:** Points are sampled identically and independently according to the natural volume measure of the manifold. For $\mathbb{S}^2$, this corresponds to a uniform spherical distribution.
* **Non-Uniform Sampling:** Points are sampled according to a biased probability density function $p(x) > 0$. For instance, on the sphere, a density bias is introduced by clumping points heavily toward the poles using a Gaussian distribution on the latitude coordinate: $$p(x) \propto \exp\left(-\frac{\phi^2}{2\sigma^2}\right)$$where $\phi$ is the latitude and $\sigma$ controls the severity of the clustering.

### 5.3 Operator Construction & Implementation Details
Given the ambient coordinates, the discrete adjacency matrix $A$ is constructed using a localized Gaussian kernel proxy $W_{ij} = \exp\left(-\frac{\|x_i - x_j\|^2}{4t}\right)$ where the bandwidth parameter $t$ scales inversely with $n$. 

Three discrete structural operators are evaluated:
1. **Uniform Anti-Laplacian ($\mathbb{L}_{uni}$):** Built directly from the uniformly sampled dataset using the standard discrete normalized anti-laplacian formula: $\mathbb{L} = I + D^{-1/2}WD^{-1/2}$.
2. **Uncorrected Non-Uniform Anti-Laplacian ($\mathbb{L}_{biased}$):** Built from the non-uniformly sampled dataset without modifying the raw kernel weights.
3. **Density-Corrected Non-Uniform Anti-Laplacian ($\mathbb{L}_{\alpha=1}$):** Built from the non-uniformly sampled dataset by first pre-computing the empirical density proxy $d_i = \sum_j W_{ij}$, creating the normalized kernel matrix $\tilde{W}_{ij} = \frac{W_{ij}}{d_i d_j}$, and computing the final operator using the normalized degree matrix $\tilde{D}$.

### 5.4 Expected Numerical Outcomes & Spectral Properties
When the discrete eigenvalues of each operator are extracted and ordered, the following behaviors are mathematically expected:
* **Convergence of $\mathbb{L}_{uni}$:** The discrete spectrum of the uniform point cloud will align tightly with the theoretical continuous spectrum curve $\gamma(\lambda) = 1 + \exp(-t\lambda)$. On $\mathbb{S}^2$, the discrete eigenvalues should cluster into distinct steps reflecting the true analytical multiplicities ($1, 3, 5, \dots$) of the spherical harmonics.
* **Degradation of $\mathbb{L}_{biased}$:** Due to the non-uniform clumping of points, the uncorrected spectrum will severely drift away from the continuous theoretical curve. The density bias $p(x)$ distorts the eigenvalues, causing a false shift in the filter's frequency response and corrupting the clean low-pass characteristics.
* **Recovery via $\mathbb{L}_{\alpha=1}$:** Upon applying the $\alpha=1$ density normalization step, the distorted eigenvalues of the non-uniform point cloud will mathematically "snap" back onto the ideal continuous curve, matching the uniform spectrum. This numerically verifies that the non-contractive low-pass filter profile is geometrically robust against real-world sample density irregularities.
